# Proyecto Posgrado

Sistema web desarrollado en Flask para la gestión de procesos académicos.

## 🚀 Funcionalidades

- Registro y gestión de usuarios
- Módulo de captura de información
- Generación y consulta de actas
- Sistema de revisión y evaluación
- Manejo de documentos PDF

## 🛠️ Tecnologías utilizadas

- Python (Flask)
- HTML, CSS, JavaScript
- SQLite (base de datos)
