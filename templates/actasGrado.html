📜 Búsqueda de Actas

Puede buscar actas ingresando el número de cuenta, el folio, un rango de fechas, el nombre de un sinodal o una combinación de ellos.
● Si ingresa número de cuenta y folio, se mostrará directamente el acta correspondiente.
● Si ingresa solo uno (número de cuenta o folio), se mostrará una lista con las coincidencias encontradas para que elija la que desea consultar.
● Si ingresa Sinodal, se listarán todas las actas donde aparezca ese nombre en el jurado.
● Si ingresa una fecha de inicio y una fecha final, se mostrarán todas las actas cuyo registro se encuentre dentro de ese rango.
● Si elige un Nivel (Especialidad, Maestría o Doctorado), se mostrarán solo las actas de ese nivel según su plan de estudios.
● Puede combinar Número de Cuenta, Folio, Nombre, Sinodal o Nivel con un rango de fechas para acotar resultados.

CAPTURA DE DATOS

Ingresa los datos del acta y adjunta el PDF.

Solo PDF. Evita escaneos muy pesados.

MODIFICAR DATOS

Busca por Número de cuenta y Folio, luego edita y guarda.

Si no subes PDF, se conserva el actual.

REGISTRAR FECHA

Ingresa número de cuenta, folio y fecha.

Busca por nombre del sinodal y, si quieres, filtra por rango de fechas del acta.
